# Start Here — ELI5 Learning Companion V0

Thanks for testing this early learning plugin.

## What it is
ELI5 helps non-technical people learn technical concepts conversationally. Pick any technical topic you genuinely want to understand — APIs, cloud, databases, AI agents, authentication, system design, DevOps, security basics, or something else.

## How to use it
1. Ask the plugin owner which supported development/plugin environment is being used, then load the package there. Do not assume that a GitHub repository or ZIP can be installed by an ordinary ChatGPT account.
2. Start with: **“I want to learn [topic].”**
3. Choose your depth:
   - **ELI5 — Understand it:** assume I know nothing.
   - **ELI15 — Understand how it works:** I’m non-technical, but I want the real terms and end-to-end flow.
   - **ELI30 — Understand how to work with it:** I’m a working professional who needs enough technical fluency to ask good questions, manage dependencies, and make decisions.
4. Take the short diagnostic. You can accept the plugin’s recommended level or keep your original choice.
5. Learn however you prefer: ask questions, ask for an explanation, or say **“Teach me through questions.”**
6. When wording really clicks, say **“Park this:”** and paste the exact text you want to keep.
7. At any point, say **“Test me”** and choose 2, 3, or 5 questions. Practice is optional.
8. When you stop for the day, say **“End session”** to get a booklet-ready summary with your parked text preserved exactly.

## Please use it naturally
Don’t try to follow a perfect path. Interrupt it. Ask basic questions. Ask difficult questions. Change levels. Skip practice. Request more questions. The purpose of this test is to see whether the learning experience adapts to you.

## Current V0 limitation
The plugin does not yet have durable cross-chat storage. Keep the same conversation while testing a topic, and copy/export the booklet output at the end of a session.

## What has not been proven yet
Static package validation and a local ZIP do not prove installation, invocation, account eligibility, or friend shareability. Record the exact product/surface and account used for any real install test.
